# Помощник рентгенолога

Сайт: https://radhelper.gitverse.site

Набираете, что описываете, — получаете шаблон заключения, чек-лист «Что проверить» и нужные классификации. КТ, рентген, маммография. Для врачей и ординаторов.

Справочный материал, не клиническая рекомендация. Сайт и репозиторий публичные — никаких ФИО, дат и номеров исследований.

## Где что лежит

- `templates/` — шаблоны заключений, порядок — `templates/order.txt`
- `ru/` — разделы-подсказки: классификации, пороги, чек-листы, порядок — `ru/order.txt`
- `tools/` — находки «что я нашёл», порядок — `tools/order.txt`, движок — `findings.js`
- `news.md` — «Что нового» на главной
- `index.html` — код сайта
- `.gitverse/workflows/pages.yml` — публикация сайта
- [SYNTAX.md](SYNTAX.md) — как писать шаблоны, калькуляторы, находки и разделы

## Как поправить файл

1. Откройте файл и нажмите «Редактировать».
2. Внесите правку, внизу коротко напишите, что поменяли, и сохраните в ветку `main`.
3. Сайт пересобирается сам. Через 1–2 минуты обновите страницу.

Не обновилось — напишите автору

## Как добавить раздел, шаблон или находку

1. В нужной папке: **+ Файл → Создать файл**, имя латиницей без пробелов, например `lirads.md`.
2. Впишите имя файла строкой в `order.txt` этой папки — там, где он должен стоять. `#` перед именем прячет файл, не удаляя его.

## Перед правкой порогов

Любую цифру отсюда кто-то потом впишет в заключение. Меняя порог, сверяйтесь с первоисточником!
