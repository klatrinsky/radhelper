# RadHelper

[Врачу](https://radhelper.gitverse.site/) — шаблоны описаний и заключений, классификации и калькуляторы. [Лаборанту](https://radhelper.gitverse.site/?lab) — расчёт контраста и дозы, памятки по КТ.

- Шаблоны — в `templates/`, подсказки — в `ru/`, находки — в `tools/`. Новый файл добавь в `order.txt` своей папки. [Формат файлов](docs/SYNTAX.md).
- Новости и примеры поиска — в `content/`. Ресурсы сайта — в `assets/`, иллюстрации к памяткам — в `img/`.
- Проверка (Node.js 18+): `npm ci && npm test`. После успешной проверки изменения из `main` публикуются автоматически.

Репозиторий публичный. Данные пациентов не добавлять. Брать можно, в коммерческих целях использовать нельзя.
