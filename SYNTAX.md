# Синтаксис: шаблоны, калькуляторы, находки, разделы

Справочник к [README.md](README.md). Здесь — как писать файлы, чтобы сайт их понял.

## Шаблоны заключений

На главной только строка «Что описываем?». Набираете «огк», «бца», «колено» — сайт показывает шаблон с кнопкой «Скопировать», а под ним подсказки из `ru/`.

Шаблоны лежат в папке `templates/`, один файл — один вариант исследования:

```
Исследование: КТ органов грудной клетки   ← одинаковое у всех вариантов одного исследования
Вариант: Без контраста                     ← название вкладки
Модальность: КТ                            ← КТ, Рентген, ММГ
Слова: огк, грудная клетка, лёгкие         ← по ним ищется, пишите все синонимы
Подсказки: fleischner, lungrads            ← имена файлов из ru/ без .md
---
Дальше текст шаблона как есть, с любыми переносами строк.
Именно он копируется кнопкой.
```

- Строка `---` обязательна: всё, что выше, — служебное, всё, что ниже, — шаблон.
- Необязательная строка `Внимание: …` в шапке показывается красной рамкой над шаблоном и не копируется. Для ограничений вроде «только для такого-то аппарата».
- Поля для заполнения пишите в квадратных скобках: `[правой]`, `[__] мм`.
- Варианты одного исследования показываются вкладками в порядке `templates/order.txt`.
- **Отдельная интерактивная страница:** необязательная строка `Страница: fractures.html` в шапке создаёт в поиске карточку со ссылкой вместо копируемого шаблона. HTML-файл размещается в корне сайта; допускаются только локальные имена `.html` без папок и внешних URL. Текст после `---` становится описанием карточки. Пример: `templates/xr-fractures.md`.

## Переключатели, поля и калькуляторы в шаблонах

Прямо в тексте шаблона, после строки `---`:

```
Кальциноз стенки {умеренный|минимальный|выраженный}.   ← переключатель: тап листает варианты
Стеноз устья {правой|левой} ВСА.                       ← первый вариант стоит по умолчанию
Протяжённость бляшки [__] мм.                          ← пустое поле: вбить число
Рентгенография [правого] коленного сустава.            ← поле с текстом по умолчанию
Минимальный просвет [Dмин] мм, дистальная ВСА [Dдист] мм.   ← поля для калькулятора
Стеноз {{NASCET}}% по NASCET.                          ← считается само
```

- **Одинаковые переключатели связаны.** Если `{правой|левой}` стоит и в описании, и в заключении, тап по одному меняет оба. Варианты должны совпадать буква в букву.
- **Пустой вариант** убирает фразу: `{|Единичные кальцинаты до 3 мм.}` — по умолчанию фразы нет, тап добавляет.
- **Именованные переключатели** связывают описание и заключение разными словами. Все `{#сердце: ...}` переключаются вместе, по номеру варианта:
  ```
  {#сердце: Тень сердца обычной конфигурации.|Тень сердца расширена, КТИ [__]%.}
  ...
  ЗАКЛЮЧЕНИЕ: ... {#сердце: |Кардиомегалия.}
  ```
  Пустой вариант показывается на сайте как «+ сердце» — по имени понятно, что включится. Строка, где остался только пустой вариант, при копировании исчезает целиком.
- **Поле и калькулятор внутри переключателя можно:** `{|Перелом [__] ребра [справа].}`, `{#сердце: Тень сердца обычной конфигурации.|Тень сердца расширена, КТИ {{КТИ}}% (сердце [Сердце] мм, грудная клетка [Грудь] мм).}`. Переключатель внутри переключателя — можно, но только один уровень: `{#ВСА П: без стенозов|стеноз за счёт {#тип П: комбинированной|кальцинированной} бляшки}`. Тап по вложенному меняет только его. Вложенным лучше давать имена: одинаковые безымянные переключатели связаны по всему шаблону, и правая сторона переключала бы левую.
- **Перечень** склеивает одинаковые находки на разных уровнях в одну строку заключения: `{{ПЕРЕЧЕНЬ: L4–L5, L5–S1 | 2 | Протрузия диска *. | Протрузии дисков *.}}` — берёт переключатели `{#L4–L5: …}`, `{#L5–S1: …}`, у которых выбран 2-й вариант, и ставит их имена через запятую вместо `*`. Одно — первая фраза, несколько — вторая, ни одного — строки нет.
  - Ещё две фразы через `|` — необязательно: пятая — когда не выбран **ни один**, шестая — когда выбраны **все** (пустая шестая — строки нет).
  - `имя=подпись` — в текст идёт подпись, а не имя переключателя: `{{ПЕРЕЧЕНЬ: ПББА П=ПББА, ЗББА П=ЗББА, МБА П=МБА | 1 | Справа до стопы прослеживается только *. | Справа до стопы прослеживаются *. | Справа ни одна артерия голени до стопы не прослеживается. | }}`.
- **Все** — фраза, только если у **всех** перечисленных переключателей выбран один и тот же вариант: `{{ВСЕ: аорта, ОПА П, ОПА Л | 1 | Гемодинамически значимых стенозов не выявлено.}}`. Так «всё в норме» в заключении появляется и исчезает само.
- **Выпадающий список.** Переключатель из 5 и больше коротких вариантов без полей и скобок показывается списком, а не листается тапом: `{#позвонок 1: L1|L2|L3|L4|L5}`. `+` перед вариантом — выбран по умолчанию: `{#позвонок 1: Th1|…|+Th12|L1}`. Одинаковые имена связаны, как у обычных переключателей.
- **Выбор нескольких** — `{*имя: +L4–L5|+L5–S1|L3–L4}`: тап раскрывает варианты, каждый включается и выключается, в текст идут выбранные через запятую. `+` — включён по умолчанию. Все `{*имя: …}` с одним именем связаны (описание ↔ заключение). Ничего не выбрано — при копировании покажет как незаполненное.
- **Связанное поле** — `[#имя]` или `[#имя = текст по умолчанию]`: все поля с одним именем заполняются вместе. Удобно, когда цифра из описания повторяется в заключении: `окклюзия протяжённостью [#ПБА П мм] мм` … `Окклюзия ПБА справа протяжённостью [#ПБА П мм] мм.`
- **`((…))` — видно, но не копируется.** Поля для расчёта прямо внутри фразы: `КТИ {{КТИ}}% ((сердце [Сердце] мм, грудная клетка [Грудь] мм))` — в РМ уйдёт только «КТИ 52%». В отличие от пульта `> `, работает внутри строки и внутри переключателя.
- **Строки-дубли на экране прячутся.** Если в строке заключения остался только «+ имя», а тот же переключатель уже есть выше в описании, строка на экране не показывается: включается он там, где виден. В копию это не влияет.
- **Незаполненное поле** копируется как `[__]`, чтобы его было видно в РМ.
- **Пульт** — строка, которая начинается с `> `: в ней поля и переключатели для расчётов (пол, возраст, прошлые цифры). Видна жёлтой плашкой, в копируемый текст не попадает. Пример: `> Пациент: {#пол: женщина|мужчина}, возраст [Возраст]`.
- **Кнопка «Сбросить»** возвращает шаблон в исходный вид.

Новый калькулятор добавляется в `index.html` в список `CALC` — там же есть образец. Калькулятор может сам переключать именованный переключатель по порогу: `toggle: "имя"` и `pick: x => номер варианта` (с нуля), как у `ЭВАНС`. Калькулятор с `text:` пишет текст вместо числа; с `set:` — невидимый, сам ставит несколько переключателей по нескольким полям (`uses:` — переключатели, при нажатии на которые он пересчитывается), как у `СМА ВЫВОД`. Калькулятор с `raw: true` и `text: (значения, tg)` получает и пустые, и отрицательные значения и номера переключателей (`tg("пол")`), как `КРИТЕРИЙ`.

## Находки («что я нашёл»)

Инструмент для случайной находки: вводишь признаки — сайт показывает вывод, что учесть и диф ряд. **В заключение ничего не копируется**, это повод задуматься. Находится тем же поиском, что и шаблоны.

Файлы — в папке `tools/`, порядок — в `tools/order.txt`, движок — `findings.js`. Пример — `tools/adrenal-mass.md`.

Шапка как у шаблона, только `Находка:` вместо `Исследование:`. После `---`:

```
# Параметры
size: Наибольший размер, мм = число              ← поле для числа
look: Структура = однородное | неоднородное      ← кнопки, первая выбрана сразу

# Расчёты
rpw: Относительное вымывание, % = (pv - del) / pv * 100

# Вывод                                           ← срабатывает ПЕРВОЕ подходящее сверху
- hu <= 10 и look = однородное → **Аденома.** Дообследование не нужно.
- иначе → Введите плотность.

# Учесть                                          ← показываются ВСЕ подходящие
- side = двустороннее → Каждое оценивают отдельно.

# Диф ряд
- ! Метастаз | https://radiopaedia.org/...        ← «!» = не пропустить
  ++ onco = есть: онкоанамнез                     ← за (++ весомее +)
  - hu <= 10: ≤ 10 HU                             ← против (-- весомее -)
  > Заметка, видна всегда.
```

В расчётах `[условие]` даёт 1 или 0 — так считают, сколько признаков есть: `maj = [wash = есть] + [caps = есть]`. Имя расчёта с `_` в начале (`_lr`) — считается, но не показывается. Пример — таблица LI-RADS в `tools/liver-lirads.md`.

Строка параметра с `; если условие` в конце видна только при этом условии, а пока скрыта, считается пустой: `feat: Признаки по ACR = … ; если risk = нет`. Так в одной находке живут два алгоритма (печень: LI-RADS для группы риска ГЦР, ACR — для остальных).

В значениях кнопок не используйте слова « и » и « или » — они разделяют условия.

Условия: `=`, `!=`, `<`, `<=`, `>`, `>=`; число можно сравнить и с другим параметром (`pv <= hu`); `и` связывает сильнее, чем `или`; просто имя — «значение введено». Пустое поле означает «не знаю»: условие с ним не срабатывает. Диф ряд сортируется по сумме «за» минус «против»; с перевесом «против» — бледнее.
## Как оформлять текст

```
# Название раздела               ← первая строка, одна решётка и пробел
> Для чего и когда применять      ← строка-пояснение под названием

Для: оба                          ← кому показывать: врач (по умолчанию, строку можно не писать) / лаборант / оба
Слова: опрос, анкета, перед КТ    ← дополнительные слова для поиска; на экран не выводятся
Виджет: contrast-volume          ← калькулятор из widgets.js на этом месте карточки
Кнопка: нет                       ← у лаборанта нет кнопки на главной, раздел находится только поиском
Срочно: да                        ← экстренный раздел: красная рамка, кнопка «Распечатать на стену»,
                                    у лаборанта — красная кнопка вверху главной и в кнопке SOS
Позвонить: Код синий | +7 985 954-11-40   ← большая красная кнопка звонка в одно касание

## Подзаголовок                   ← две решётки

Обычный абзац. **Жирный текст** — двумя звёздочками с каждой стороны.

- пункт списка                    ← дефис и пробел
- ещё пункт

1. нумерованный шаг               ← цифра, точка и пробел
2. следующий шаг

`Формула = (А − Б) / А × 100%`     ← строка целиком в обратных кавычках

| Колонка 1 | Колонка 2 |         ← таблица: первая строка — заголовки
|---|---|                          ← обязательная строка-разделитель
| ячейка | ячейка<br>вторая строка ячейки |

![Что на картинке — словами](img/схема.svg)   ← картинка отдельной строкой; файл кладите в папку img/
                                             две картинки строками подряд — встанут в ряд

Источник: Автор, журнал, год. [ссылка](https://...)
Radiopaedia: [Название статьи](https://radiopaedia.org/articles/...)
```

Ссылку на Radiopaedia берите из адресной строки открытой статьи. Если статьи нет, можно дать ссылку на поиск: `https://radiopaedia.org/search?scope=articles&q=запрос+через+плюс`.

## Таблицы: три правила, чтобы не развалить

1. **Одна строка таблицы — одна строка в файле.** Не нажимайте Enter внутри ячейки. Перенос внутри ячейки — `<br>`.
2. **В каждой строке столько же вертикальных черт `|`, сколько в заголовке.** Пустая ячейка — просто `| |`.
3. **Символ `|` внутри текста ячейки не используйте** — он считается границей колонки.

Пропущенная черта или лишний Enter дают кривую таблицу, а не ошибку. После правки откройте раздел на телефоне и проверьте глазами.
